# Curso: Recurrencia en el Desarrollo de Software — Máster de Desarrollo de Software.
## Ejercicios: Modelado de documentos en lenguage XML

|    **Ejercicio**    |    **Documento**    |    **Descrición**    |
| :----:              | :----:              | :----                |
| Agenda de contactos | agenda.xml          |Estructura básica con ID's por cada entrada y referencias a contactos sustitutos mediante dicho ID|
| Menu en Chrome | chrome_menu.xml          |Arbol jerarquico definido por niveles de menu y submenu|
| Curriculum personal | curriculum_eder.xml |Estructura no homogénea con diferentes secciones y jerarquias|
| Horario de clases | schedule.xml          |Modela una matriz y usa atributos para definir inicio y fin|
